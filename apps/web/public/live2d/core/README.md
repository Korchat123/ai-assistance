# Cubism Core

Download the official Cubism SDK for Web and copy its
`live2dcubismcore.min.js` file into this directory for local use:

```text
apps/web/public/live2d/core/live2dcubismcore.min.js
```

Cubism Core is proprietary software and is intentionally ignored by Git. Review
Live2D's current SDK license and release-license requirements before shipping or
redistributing it.
